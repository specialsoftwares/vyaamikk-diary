## Fixtures

Directory: `docs/release/packets/letterhead/pdf-fixtures/`

Generated by `composeLetterheadHtml` (production pure composer) via
`letterheadPdfRender.inspection.test.ts`. Fresh required PDFs must be rendered
into a run-local `pdf-fresh-*` directory — **committed `pdf/` does not count**.
Host Chrome/Chromium PDFs are **not** a substitute for device Print.

| Case | Observation |
|---|---|
| `imported-contain-top.html` | Wide page; `object-fit: contain` + `object-position: top center` |
| `imported-tall.html` | Tall page; same contain/top geometry (not width-only fit) |
| `imported-a4ish.html` | Ordinary near-A4 portrait |
| `generated-left/center/right.html` | Header flex; right = row-reverse + flex-start; long bilingual details |
| `multi-page-body.html` | Long body + grayscale + `@page` margins; inspect for clipping / header / body overlap |
